# 🚀 마크 미너비니 SEPA 트렌드 템플릿 국내 주식 스크리너 & 대시보드

마크 미너비니(Mark Minervini)의 대표 저서 *『성장주 수급의 법칙(Trade Like a Stock Market Wizard)』*과 *『초수익 성장주 투자법(Think & Trade Like a Champion)』*에 소개된 **SEPA(Specific Entry Point Analysis) 트렌드 템플릿(Trend Template)**을 국내 주식(코스피/코스닥)에 적용한 자동 스크리너입니다.

GitHub Actions를 통해 **평일 매일 장 마감 후(오후 4:30) 자동으로 종목을 스캔하고, 인터랙티브 웹 대시보드를 생성하여 GitHub Pages로 자동 배포**합니다.

## 🎯 SEPA 종합 추천 점수 시스템 (100점 만점)

단순히 주가만 많이 올라서 RS만 높은 종목이 아니라, **신고가에 가장 바짝 붙어있고 최근 변동성이 꽉 쥐어짜여 즉시 돌파가 가능한 '진짜 미너비니식 매수 후보'**를 발굴하기 위해 5대 지표를 종합 가중 평가합니다:

| 평가 항목 | 배점 | 설명 및 기준 |
| :--- | :---: | :--- |
| **1. IBD 상대강도 모멘텀** | **35점** | 3개월(40%) + 6개월(20%) + 9개월(20%) + 12개월(20%) 가중 수익률 기준 전체 시장 백분위 순위 (RS 95점 이상 35점 만점) |
| **2. 52주 신고가 근접도** | **25점** | 52주 최고가 대비 괴리율 (고점 돌파 직전 -3% 이내 25점 만점, -7% 이내 22점) |
| **3. VCP 변동성 축소 패턴** | **20점** | 최근 20일 변동성 대비 60일 변동성 비율 (`ATR20 / ATR60`). 변동성이 극도로 수축될수록(0.70 미만 20점 만점) 피봇 돌파 임박 |
| **4. 정배열 및 200일선 가속도** | **10점** | 50일선 > 150일선 > 200일선 완전 정배열 및 200일선 최근 1개월 상승 기울기 |
| **5. 거래대금 유동성** | **10점** | 최근 20일 평균 거래대금 (100억~500억 이상 기관 수급 유입 가능 종목 우대) |

### 🏆 추천 등급 체계
- **👑 다이아몬드 (90점 이상)**: VCP 수축 완료 + 신고가 돌파 직전 + 초강력 RS를 겸비한 최우선 매수 후보
- **💎 골드 (80 ~ 89점)**: 우수한 추세 지속형 주도 성장주
- **⭐ 실버 (70 ~ 79점)**: 트렌드 템플릿 기본 조건 통과 종목

## 📋 마크 미너비니 트렌드 템플릿 8대 원칙
1. 주가가 150일선 및 200일 이동평균선 위에 위치
2. 150일 이동평균선이 200일 이동평균선 위에 위치
3. 200일선이 최소 1개월(20영업일) 이상 상승 추세
4. 50일 이동평균선이 150일선 및 200일선 위에 위치 (정배열)
5. 현재 주가가 50일선 위에 위치
6. 현재 주가가 52주 신저가 대비 +25% 이상 상승
7. 현재 주가가 52주 신고가 대비 25% 이내 (-25% 이내)
8. IBD 가중 상대강도(RS Rating) 최소 70점 이상

## 🛠️ 로컬 실행 방법

