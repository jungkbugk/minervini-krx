# 🤖 마크 미너비니 SEPA 한국투자증권 24/7 퀀트 자동매매 시스템

한국투자증권(KIS) Open API를 연동하여 마크 미너비니의 고승률(62.7%) SEPA VCP 전략을 100% 무인으로 실행하는 퀀트 자동매매 프로젝트입니다.

---

## 📁 폴더 내 주요 파일 구성

| 파일명 | 설명 |
| :--- | :--- |
| **`01_퀀트봇_24시간_무인실행.bat`** | **[메인]** 더블 클릭 한 번으로 24시간 365일 무인 자동매매 데몬 가동 |
| **`02_계좌및슬롯현황_조회.bat`** | 현재 예수금, 총자산, 4개 슬롯 점유 상태 및 보유 종목 즉시 확인 |
| **`03_가상매수_시뮬레이션.bat`** | 실제 주문을 전송하지 않고 가상으로 매수 종목과 수량을 계산해 보는 테스트 |
| **`04_한투계좌_재설정.bat`** | 한국투자증권 AppKey, AppSecret, 계좌번호 재설정 도우미 |
| **`quant_bot.py`** | 24/7 데몬 메인 엔진 (장중 실시간 매수/매도 감시 및 텔레그램 연동) |
| **`kis_api.py`** | 한국투자증권 REST API 통신 및 24시간 토큰 자동 캐싱 모듈 |
| **`kis_config.json`** | 내 한투 API 키 및 계좌 설정 (로컬에만 안전하게 보관됨) |
| **`portfolio.json`** | 퀀트 봇 전용 포트폴리오 관리 파일 |

## ⏰ 24/7 데몬 동작 주기 및 행동 규칙

- **야간 / 주말 / 휴일**:
  - 초저전력 대기 모드 (CPU 점유율 0%)
  - 콘솔에 다음 개장일까지 남은 시간을 카운트다운하며 안전 대기
- **평일 오전 08:50 (장 시작 10분 전)**:
  - 자동으로 깨어나 토큰 유효성 검사 및 계좌 잔고 확인
  - 코스피/코스닥 지수 50일선 시장 레짐(Market Regime) 사전 점검
  - 스마트폰 텔레그램으로 **[☀️ 장 시작 준비 완료 브리핑]** 발송
- **평일 오전 09:01 (장 개장 직후)**:
  - 시장 레짐이 🟢 정상일 때만 동작 (지수 50일선 아래 조정장이면 신규 매수 전면 차단)
  - 빈 슬롯(최대 4개)에 총자산의 25%씩 균등 분할 배정
  - 엄격한 VCP 수축(ATR20/ATR60 ≤ 0.88), 52주 고점거리(-12% 이내) 1위 주도주 자동 매수 주문
  - 체결 즉시 텔레그램으로 상세 내역(수량, 매수가, 손절선) 발송
- **평일 장중 09:01 ~ 15:30 (실시간 정밀 감시)**:
  - 30초 주기로 보유 종목의 실시간 시세를 추적
  - **-7.5% 초기 손절선** 터치 시 즉시 시장가 전량 손절
  - **+22.5%(3R) 이상 수익 도달 시** 손절선을 **매수가(0%, 본전)로 자동 상향**하여 원금 영구 보호
  - 고점 대비 **-10% 트레일링 스탑** 반락 시 시장가 전량 익절
  - 체결 즉시 텔레그램으로 실현 손익 발송
- **평일 오후 15:35 (장 마감)**:
  - 당일 계좌 총자산 및 실현손익 일일 결산
  - 스마트폰 텔레그램으로 **[🌙 장 마감 일일 결산 리포트]** 발송
  - 당일 매수 플래그 초기화 후 다음 거래일 오전 08:50까지 안전 대기 모드로 진입

## 🛡️ 시스템 안정성 보장 기능

1. **윈도우 절전 모드 자동 방지**: 프로그램이 실행 중일 때는 컴퓨터가 절전 모드(Sleep)로 꺼지지 않도록 Windows API(`SetThreadExecutionState`)를 자동 호출합니다.
2. **네트워크 장애 자동 복구**: 가정집 인터넷 일시 단절, Wi-Fi 재연결, 증권사 점검 시에도 프로그램이 강제 종료되지 않고 15초 대기 후 자동으로 재연결을 시도합니다.
